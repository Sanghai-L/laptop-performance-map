# 型号库范围与来源

资料核对：2026-10-23。收录 261 项型号 / 配置。Apple 的不同 CPU / GPU 核心组合、Qualcomm 的不同完整料号分别计数，不将其混称为 261 个完全不同的芯片设计。

- Intel 142 项：Core Ultra 100 / 200 / 300 移动系列，200HX Plus；Core 100 / 200 / 300；第 12 / 13 / 14 代主要移动 Core i；N 与 Core N 系列。
- AMD 76 项：Ryzen AI Max、AI 400 / 300、Ryzen 400 / 200、9000HX，以及 8000 / 7000 的主要 U / HS / HX 型号。
- Apple 25 项：M2 至 M5 的常见基础 / Pro / Max 笔记本配置，以及 MacBook Neo 的 A18 Pro。
- Qualcomm 18 项：Snapdragon X / X Plus / X Elite、X2 Plus / X2 Elite / X2 Elite Extreme 的公开笔记本料号。

范围以主流零售和通用商务笔记本为主。地区特供 H 名称、少见的 PRO / vPro 派生、较早的库存或翻新产品可能仍有遗漏。厂商仍提供规格页不表示某地商店当日有货，因此不提供未经统计的“市场覆盖率”，也不把目录收录当作库存证明。桌面 CPU、嵌入式型号、开发套件不作为默认范围。

## 来源与复核方法

Intel 来自厂商移动处理器比较 PDF、产品规格页及 200HX Plus 发布规格；AMD 来自官方笔记本目录内的结构化产品规格和逐型号产品页；Apple 来自各代 MacBook 技术规格；Qualcomm 来自官方产品表与产品简报。每个条目保留直接来源链接。

保留初版 12 条的链接 ID，确保先前复制的型号链接仍可打开。将 Apple 的汇总配置拆为具体核心组合；原来的 `m5` 对应 10 CPU / 8 GPU，`m5pro` 对应 15 CPU / 16 GPU，`x2` 对应 X2E-88-100。

任务区集中解释编译、剪辑、CPU 渲染：按 Intel N / U / P / H / HX / 200V / B 系列、AMD 不同定位、Apple 基础 / Pro / Max 与 Windows Arm 区分，再结合具体型号的核型、核心线程、GPU 和内存条件。相同 CPU 配置只改 GPU 的条目，不编造编译差距。办公和云端 AI 的共通知识集中在小课堂。

核显模块在 `gaming-evidence.json` 中收录 134 条原始测评证据，区分单机平均、跨整机 / 模式均值范围、数据库聚合和游戏过程观察。358H / B390 的 2077 1080p 低 / 中画质原生范围来自 8 款具名笔记本；黑神话与无畏契约使用实际测试设置。新增 Max+ 388 / 8060S 的直接整机测试与其他 Halo 核显锚点。缺测试的游戏 / 核显组合按性能给出宽范围估算，明确标为“性能估算 · 非实测”。原神与无畏契约有额外 392 / 8060S 样本校准；独立游戏拆为原版星露谷和第一代哈迪斯，逐项估算，不套成所有独立游戏的结论。

每项游戏可展开原文、机器、内存、功耗、版本与渲染方式；未提取字段保留缺失，不暗示统一条件。带同一 GPU 的其他 CPU 明示“同核显参考”。无畏契约 Arm 限制依据 Riot 官方要求，无核显型号直接说明需要另配显卡。

## 验证

本地隔离 Edge 验证了 783 个 CPU / 任务组合、20 个核显边界型号 / 游戏组合、品牌系列及核显搜索、36 个整机实验室组合、小测、旧链接恢复和键盘导航；另核对帧率设置切换、358H 八台样本与 200V 内存规格。320 / 375 / 768 / 1440 像素宽度未出现页面横向溢出，桌面和手机截图经过视觉复核。该验证证明网页交互与布局，不是硬件性能实测。


## 性能估算方法

`dist/estimates.js` 包含各核显家族的各游戏 1080p 原生低画质参考带，覆盖现有目录的集显配置；中画质按各游戏负载使用单独的宽松降档估计。它是人工校准的入门教学估计，不是训练出的预测模型或统计置信区间。没有从单个 3DMark 分数线性换算所有游戏，也不把 CPU 核心数当图形算力。Halo、Arc、RDNA、旧 Vega、Intel UHD / Xe、Adreno 与 Apple 的平台 / 架构分开处理。

估算假设插电、正常驱动、相应性能模式和足够内存 / 带宽；Halo 通常至少 32GB，其他平台至少 16GB。8GB / 单通道或严重限功耗配置可能低于区间，特殊场景与新补丁也可能超出。原神和星露谷限制到常规 60 FPS；哈迪斯缺少同配置受控测试，明确说明估算更粗。Arm 反作弊、Mac 无官方客户端、A18 未满足 2077 Mac 官方要求以及无核显不使用估算假装能运行。

公开测试优先；缺项自动显示估算。有实测时，也可切换查看统一 1080p 条件的估算，显示方式、来源与口径分开。`catalogue/estimate-anchors.json` 保留第四版的实际锚点及单独的估算记录。

第四版隔离 Edge 检查覆盖 2,920 个合法估算 / 设置组合、52 个核显配置组，212 个无核显或平台边界返回限制说明，无兼容组合因缺测试而留空；检查实测 / 估算切换、画质区间变化与 388 直接样本优先。320 / 375 / 768 / 1024 / 1440 像素无页面横向溢出，截图已复核。
