# Changelog

English · [简体中文](CHANGELOG.zh-CN.md)

## 1.2.1 · 2026-10-23

- Shortened the homepage, CPU summaries, task explanations, and naming guidance. Copy now focuses on suitable workloads, limits, and model differences.
- Made “Suffixes and labels” and “Rules and exceptions” visible by default in separate cards, with the suffix reference first.
- Increased reference body text to 14px with more line spacing and padding. Mobile references use vertical cards; suffixes such as HX stay on one line.
- Updated both languages, completed English translations, and removed the repetitive closing summary.
- Updated the Android offline app with all changes, including the naming module introduced in 1.2.0.

## 1.2.0 · 2026-10-23

- Added CPU naming guidance for Intel, AMD, Apple, and Qualcomm, distinguishing current and older naming systems.
- Added 45 interactive examples and 33 suffix or label entries. Select a name fragment to see its meaning.
- Added a direct link from the CPU profile to the current model’s name breakdown, covering all 261 catalog configurations.
- Explained family-specific rules and exceptions: Core versus Core Ultra, Ryzen AI versus traditional Ryzen, Apple chip versus laptop names, and complete Snapdragon part numbers.
- Added Chinese and English content, keyboard navigation, mobile layouts, and official references.

The 1.2.0 naming features first appeared on the website and are included in this GitHub 1.2.1 release. No separate 1.2.0 APK was distributed.
